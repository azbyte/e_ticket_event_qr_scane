# Skill debugging

Catat gejala dan langkah minimum; gunakan data sintetis. Telusuri alur state/API
berdasarkan kode aktual dan bedakan sebab terbukti dari hipotesis. Jangan
menampilkan secrets atau data pribadi. Tambahkan regression test yang mengunci
perilaku bila memungkinkan, jalankan checks terdampak, lalu laporkan diagnosis,
perbaikan, hasil dan keterbatasan integrasi/perangkat.
