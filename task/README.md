# ARSIP HISTORIS — jangan dibaca AI

Folder ini **bukan** sumber instruksi aktif. Isinya status kerja lama, laporan
developer, audit, dan proposal yang sudah selesai atau digantikan.

- **AI/assistant:** jangan membaca file di sini kecuali pemilik proyek menyebut nama
  file atau tugasnya secara eksplisit. Aturan yang masih berlaku ada di
  [`../AGENTS.md`](../AGENTS.md).
- **Manusia:** folder ini disimpan untuk penelusuran sejarah dan bukti pekerjaan.

## Isi

| Lokasi | Keterangan |
|---|---|
| `archive/` | Laporan, handover, audit, dan dokumen pra-audit yang sudah digantikan |
| `AUDIT_PROYEK/` | Snapshot audit struktur, dependensi, PRD, dan kesiapan demo |
| `TAHAP_1/`, `TAHAP_2/`, `TAHAP_3/` | Task, ownership, kontrak integrasi, dan laporan per tahap |
| `FASE_1C/1D/1E*.md` | Register authorization, unblocking, dan ledger eksekusi |
| `*_AUDIT_FINAL.md`, `DB_CHANGE_PROPOSAL.md`, `PRD_TRACEABILITY_MATRIX.md` | Audit dan proposal database |
| `PEMBAGIAN_TUGAS_FINAL.md`, `FINISHING_AUTHORITY.md`, `RUNBOOK_OPERASIONAL.md` | Controller tugas dan otoritas DB (historis) |
| `LAPORAN_PEMBERSIHAN_PROYEK.md` | Catatan pembersihan repository terakhir |
