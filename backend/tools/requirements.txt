# Dependensi alat validasi e-tiket (BUKAN dependensi runtime backend).
#
# Dipakai hanya oleh skrip manual validasi e-tiket:
#   - tools/render_ticket_pdf.py      (render PDF -> PNG)
#   - tools/check_qr_scannability.py  (ukur modul & quiet zone QR)
#   - tools/decode_ticket_qr.py       (bukti QR dapat dipindai, memakai OpenCV)
#   - _verify-out/make_artwork.py     (artwork uji bergaya desain penyelenggara)
#
# Pasang di virtual environment proyek (bukan global) dari folder `backend/`:
#   py -3.14 -m venv .venv
#   .\.venv\Scripts\python.exe -m pip install -r tools/requirements.txt
#
# Catatan nama paket vs nama modul:
#   - paket `PyMuPDF`     -> `import pymupdf` (PyMuPDF 1.24+); `import fitz` juga
#     tersedia sebagai nama lama. Kode di folder ini memakai `pymupdf` karena
#     API yang dipakai (Matrix, Pixmap) berasal dari PyMuPDF versi tersebut.
#   - paket `opencv-python-headless` -> `import cv2`.
#   - paket `Pillow`      -> `import PIL` (dipakai `_verify-out/make_artwork.py`
#     untuk membuat artwork uji sebelum PDF dirender/diperiksa visual).
#
# PyMuPDF 2.x = API 1.28 (distribusi 2.2 memasang modul 1.28.6); rentang di
# bawah menerima keduanya tanpa mengubah nama import.
PyMuPDF>=1.24,<3
opencv-python-headless>=4.10,<6
