--------------------------------------------------------------------------------
RINGKASAN ARSITEKTUR
--------------------------------------------------------------------------------

1. BACKEND (Node.js + Express)
   - Bahasa: JavaScript | Framework: Express.js
   - Database: PostgreSQL via Supabase | Auth: JWT
   - Fitur: Generate & parse QR code | Port: 5000

2. FRONTEND MOBILE (Flutter)
   - Bahasa: Dart | Framework: Flutter SDK 3.13.2+
   - State Management: Provider
   - Platform: Android, iOS, Web, Windows, macOS, Linux
   - Fitur: Auth, browse event, beli tiket, QR tiket, scan verifikasi
            manajemen event, riwayat check-in, notifikasi, laporan

3. FLOW DATA
   Mobile App (Flutter) --> HTTP Request --> Backend API (Node.js/Express)
   --> Supabase (PostgreSQL)
